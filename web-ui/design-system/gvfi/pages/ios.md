# iOS Page Overrides

> **PROJECT:** GVFI  
> **Page Type:** iOS Human Interface (Web)

> Overrides Master for all routes when iOS theme is active.

---

## Color Overrides

- **Primary:** `#007AFF` (iOS Blue) / `#0A84FF` dark
- **Background:** `#F2F2F7` grouped list gray
- **Card:** `#FFFFFF` / `#1C1C1E` dark
- **Label secondary:** `#8E8E93`

## Typography

- **Stack:** `-apple-system`, Inter, Noto Sans SC
- **Large Title:** 34px bold (navigation)
- **Headline:** 17px medium
- **Footnote:** 13px

## Layout

- **Grouped lists:** `ios-grouped` rounded-xl white on gray
- **Nav bar:** blur + safe area (`ios-blur-bar`, `ios-safe-top`)
- **Mobile workspace:** bottom tab bar (4 tabs), `pb-24` content inset
- **Touch targets:** min 44px height

## Components

- Buttons: filled blue or gray secondary, `rounded-xl`, no pill shadow
- Section headers: uppercase 13px above grouped card
- KPI: 2×2 grid inside single grouped card
